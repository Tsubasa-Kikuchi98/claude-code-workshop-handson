# PR説明文ジェネレーター

このスキルは、いま手元にある変更から PR の説明文ドラフトを生成します。

## 進め方

1. **変更内容を取得する**
   - git リポジトリなら `git diff HEAD`（未コミット分）または `git diff main`（main との差分）を読む
   - git が無い場合は、ユーザーが直近の会話で説明した変更内容を使う

2. **変更の種類を判定する**
   - 新機能の追加 → `templates/feat.md` だけを読む
   - バグ修正 → `templates/fix.md` だけを読む
   - リファクタリング（外部挙動を変えない整理） → `templates/refactor.md` だけを読む
   - 複数該当する場合は **主題のテンプレ 1 つだけ** を選ぶ（残り 2 つは読まない）

3. **テンプレの各セクションを埋める**
   - 差分から読み取れる事実だけで埋める
   - 差分から読み取れない情報（背景・動機・本番影響など）は **`[要記入]`** のまま残す
   - 推測で書きたい内容は **「（要確認）」** とラベル付きで書く

4. **最後にセルフレビューを促す**
   - `reference/self-review-checklist.md` を読み込み、PR 提出前に確認すべき項目を箇条書きでユーザーに提示する

## 守ってほしいこと

- テンプレのセクション見出し（`## 〜`）は変えない
- ファイル名・関数名・コードブロックは差分から積極的に引用する
- 出力は 1 つの Markdown コードブロックにまとめる（そのままコピペできるように）
