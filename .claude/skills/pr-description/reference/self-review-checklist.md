# PR 提出前のセルフレビュー

PR 説明文を書き終えたら、提出前に以下を確認してください。

## 内容
- [ ] タイトルが 50 文字以内で、何の PR か一目で分かる
- [ ] 「概要」だけ読めばレビュアーが内容を把握できる
- [ ] `[要記入]` のプレースホルダーがすべて埋まっている
- [ ] 動作確認手順が、レビュアーが追試できる粒度で書かれている

## コード品質
- [ ] デバッグ用の `console.log` を消した
- [ ] 機密情報（APIキー・パスワード等）を含んでいない
- [ ] コメントアウトされた古いコードを削除した

## 影響範囲
- [ ] 既存機能を壊していないことを動作確認した
- [ ] 設定ファイル・スキーマを変えた場合、移行手順を書いた
- [ ] 公開 API の互換性を破る変更がある場合、その旨を明記した
